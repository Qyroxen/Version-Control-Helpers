## What is it?

Version Control Helpers is a production-ready CLI tool built with Go. It provides powerful functionality with a beautiful terminal interface.

## Features

- Fast and efficient (written in Go)
- Beautiful CLI with colored output
- Comprehensive documentation
- GitHub Actions CI/CD
- CodeQL security analysis
- Dependabot for dependency updates
- MIT Licensed
- Fully offline - zero cloud dependency

## Quick Start

```bash
# Install
git clone https://github.com/Qyroxen/Version-Control-Helpers.git
cd Version-Control-Helpers
go build -o versioncontrolhelpers .

# Run
./versioncontrolhelpers --help
```

## CLI Usage

```bash
# Basic usage
./versioncontrolhelpers

# With flags
./versioncontrolhelpers --verbose --output json

# Get help
./versioncontrolhelpers --help
```

## Examples

```bash
# Example 1
./versioncontrolhelpers example1

# Example 2
./versioncontrolhelpers example2 --flag value
```
